# PhonoPy note

phonon dispersion with phonopy

0. Prepare
   + relaxed unit-cell POSCAR
   + static-force VASP inputs: INCAR, KPOINTS, POTCAR
   + do NOT relax displaced supercells

1. Generate displacements (5*5*1)
   `phonopy -d --dim 5 5 1 --pa auto`

2. Create folders
   + unix: `for i in $(seq -w 1 24); do mkdir -p "disp-0$i"; done`

3. Run VASP for each displaced supercell   
   + copy POSCAR-xxx to each disp-xxx/POSCAR
   + run static calculations
   + collect vasprun.xml

4. Create FORCE_SETS
   + unix: `phonopy -f $(ls disp-*/vasprun.xml | sort -V)`

   + windows (PowerShell):
      phonopy --vasp -f (Get-ChildItem -Directory -Filter "disp-*" |
      Sort-Object { [int]($_.Name -replace '^disp-','') } |
      ForEach-Object { "$($_.Name)\vasprun.xml" } |
      Where-Object { Test-Path $_ })

5. Provide band.conf

6. quick look
   `phonopy -p band.conf`

7. Optional quick plot from yaml
   `phonopy-bandplot band.yaml -o band.pdf`
