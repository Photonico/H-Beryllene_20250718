# G-Beryllene

Investigate the structural, electronic, optical, and topological properties of g-Beryllene.

* colors correspondence: hexagonal family
    0. [a0] α-Beryllium bulk: blue
    1. [a1] α-Beryllene monolayer: orange
    2. [g1] g-Beryllene monolayer: yellow
    3. [g2a] g-Beryllene bilayer AA stack: green
    4. [g2b] g-Beryllene bilayer AB stack: lime
    5. [g3a] g-Beryllene trilayer AAA stack: purple
    6. [g3b] g-Beryllene trilayer ABA stack: violet

* colors correspondence: cubic family
    0. [c0] c-Beryllene bulk: blue
    1. [c1] c-Beryllene monolayer: orange
    2. [c2] c-Beryllene bilayer: lime
    3. [c3] c-Beryllene trilayer: violet
